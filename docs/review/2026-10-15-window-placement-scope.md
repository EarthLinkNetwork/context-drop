# ウィンドウの表示先・表示ショートカット・最前面 (v0.1.8) — review scope

## 保証すること
- 「ウィンドウを表示/隠す」のグローバルショートカット（既定 `CommandOrControl+Shift+0`、設定で変更可、空なら無効）。手前にあるときは隠し、それ以外は表示する。Capture 切り替えのショートカットと同じ組み合わせにすると登録を拒否し、画面に警告を出す（Capture 側を奪わない）。
- 表示先（設定「Open window on」）: マウスのある画面（既定）／指定したディスプレイ（未接続ならマウスのある画面）／前回の位置（フォーカスが外れたとき・隠したとき・終了したときに保存し、起動時に、その位置が接続中の画面上にあるときだけ戻す）。メニューバーアイコンのクリックと「Show Window」も同じ設定に従う。ウィンドウがすでに目的の画面にあるときは動かさない。
- 解像度の違う画面が混ざっていても、目的の画面に出る（macOS では各値をその画面自身の倍率で point に戻して計算する）。画面の境目ちょうどにマウスがあるときは、マウスが乗っている側の画面を選ぶ。
- 別の画面へ移すときは、移動が終わってから表示する（元の画面に一瞬出てから移る、ということがない）。
- 最前面（Always on top）を設定画面とメニューバーのメニューの両方で ON/OFF でき、1 つの保存値として両方が同期する。トレイの切り替えは `alwaysOnTop` のキーだけを書き、読み込みに失敗したときは何も書かない（ほかの設定を既定値で上書きしない）。保存に失敗したときはチェック表示を保存値に戻す。
- 設定画面で保存前に編集中の項目は、別の項目の保存値が変わっても（トレイでの最前面の切り替えなど）消えない。
- すべてのデスクトップ（Space）に表示する設定。
- 既存の設定（Capture ショートカット、TTL、サイズ上限）と、v0.1.7 以前に保存された設定 DB はそのまま読める（新しいキーが無ければ既定値になる）。
- 版を 0.1.8 にそろえる（tauri.conf / plugin / marketplace / CHANGELOG）。

## 保証しないこと
- 右クリックでウィンドウを出すこと（右クリックはメニューだけ。左クリックを離したときに 1 回だけ表示する）。
- Dock の「割り当て先」メニューそのものの再現（Dock アイコンのない accessory アプリには、そのメニューを出す公開 API がない）。代わりに上の設定で同じ結果を出す。
- Windows / Linux の実機での位置の正しさ（物理座標をそのまま使う実装で、CI のビルドだけで確かめる。実機での E2E は macOS だけ）。
- ドラッグ中の位置を毎回保存すること（フォーカスが外れたとき・隠したとき・終了したときにだけ保存する）。

## 前提
- tauri 2.12.1 / tao 0.37.1 の macOS 実装: モニターの物理座標は「point × その画面の倍率」、カーソルの物理座標は「point × メイン画面の倍率」、`set_position(Logical)` はグローバルな point 座標。
- メインスレッドから呼んだ tauri の getter は、その場で直接処理される（`send_user_message` が main thread を判定する）ので、トレイやウィンドウイベントの処理から呼んでもデッドロックしない。

## 受け入れる限界
- 移動の完了を待つのは最大 約 200ms。メインスレッドが混んでいて移動がそれより遅れると、元の画面で表示されてから移る。
- ディスプレイの選択肢の名前は tao が返す名前（macOS では `Monitor #<型番>`）。見分けやすいように解像度と「main」を添える。
- 「すべてのデスクトップに表示」は `CanJoinAllSpaces` だけで、フルスクリーンのアプリの Space には出ないことがある。
- トレイで最前面を切り替えた直後（画面の再取得の前）に設定画面で保存すると、設定画面が持っていた古い値で戻ることがある。
- ショートカットの登録処理と振り分けは tauri の crate の中にあり単体テストが無い。実機で確かめる（Capture と同じ組み合わせにして押すと Capture が切り替わること）。
- 既定値は OS の既定ショートカット（`com.apple.symbolichotkeys`）と重ならないものを選んだが、ほかのアプリが同じ組み合わせを横取りしても登録は成功扱いになることがあり、その場合は警告が出ない。
- 同じ名前のモニターが 2 台あり、しかも配置を変えた場合は、名前が一致する最初の 1 台を選ぶ。
- 表示先の計算は純粋関数（`context_drop_core::placement`）を単体テストで確かめる。実際の画面上の位置は、v0.1.8 を /Applications に入れて実機で確かめる（マウスを別の画面へ移してショートカットを押し、ウィンドウの位置を読む）。
